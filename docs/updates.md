# Журнал оновлень бойового сервера

Нові записи додаються **зверху**. Скрипт `scripts/update.ps1` показує на сервері саме нові рядки цього файлу перед оновленням. Кожен запис — для людини, без жаргону.

Формат запису:

```
## ДАТА — коротка назва
Що нового: ...
Потрібен бекап: так/ні (так — якщо міграція змінює чи видаляє існуючі дані)
Потрібен seed: так/ні (лише коли додано нові довідники/шаблони; команду див. у docs/deployment.md)
Що перевірити після оновлення: ...
```

## 2026-10-20 — Звіт по днях з Excel і кнопка «Відпрацьований час» у боті
Що нового: у «Табелі» з'явилась кнопка «Звіт по днях» (працівник × календарний день, групи за підрозділом, підсумки, фільтри за періодом, підрозділом і працівником) та експорт у Excel. У Telegram-боті — головне меню кнопками (відпрацьований час, задачі, новини, відпустка), команди `/menu` і `/worktime`: працівник бачить свої години за поточний місяць. Додано пакет `exceljs` (встановиться через `npm ci`).
Потрібен бекап: ні (база не змінювалась, міграцій немає)
Потрібен seed: ні
Що перевірити після оновлення: у «Табелі» відкрити «Звіт по днях» і натиснути «Експорт в Excel» (файл відкривається, підсумки збігаються з екраном); у боті написати `/menu` — мають з'явитись кнопки, «⏱ Відпрацьований час» показує години за місяць.
