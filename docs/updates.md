# Журнал оновлень бойового сервера

Нові записи додаються **зверху**. Скрипт `scripts/update.ps1` показує на сервері саме нові рядки цього файлу перед оновленням. Кожен запис — для людини, без жаргону.

Формат запису:

```
## ДАТА — коротка назва
Що нового: ...
Потрібен бекап: так/ні (так — якщо міграція змінює чи видаляє існуючі дані)
Потрібен seed: так/ні (лише коли додано нові довідники/шаблони; команду див. у docs/deployment.md)
Що перевірити після оновлення: ...
```

## 2026-10-18 — Перший випуск (версія 1.0)
Що нового: увесь функціонал на цей момент — оргструктура, права, найм і навчання, атестація по компетенціях, оцінювання, переведення, заморозка, відпустки, звільнення, оголошення, опитування, облік робочого часу (термінал, табель), обходи магазинів (ділянки, регламент, порушення), аналітика.
Потрібен бекап: ні (чиста установка за docs/deployment.md)
Потрібен seed: так, один раз: `SEED_MODE=production` (див. docs/deployment.md)
Що перевірити після оновлення: вхід під першим адміністратором, відкриття сторінки «Структура».
